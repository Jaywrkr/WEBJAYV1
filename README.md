# Jay es ___ — v4

Web personal de Jay Jaramillo (jaywrkr). Una sola historia con scroll: "Jay es ___" queda fija a la izquierda y la palabra se reescribe en cada capítulo (ingeniero, diseñador, escritor, líder, VJ, creador). Cada capítulo se abre con una ventana cuadrada que crece con el scroll. Cada proyecto se abre como caso, creciendo desde el botón que lo abre.

## Contenido
Todo vive en `PJ` (proyectos) y `CH` (capítulos) dentro de `index.html`. Las imágenes son marcadores (`.ph`) con la descripción de lo que va: se reemplazan por `<img>` o `<video>` reales.

## Stack
HTML, CSS y JavaScript. GSAP + ScrollTrigger y Lenis desde CDN. Sin build.

## Brand
Negro y blanco. Geist Mono 300/400, nunca bold, máximo 56px. Solo ángulos rectos. Cierra con "simple."
